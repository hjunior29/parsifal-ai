{% trans "Supported review methodologies" %}

{% trans "Pick the review type when creating a review. Parsifal adjusts the protocol sections, checklists, screening rounds, and charts accordingly." %}

Systematic Literature Reviews

Kitchenham 2007

Complete planning, conducting, and reporting process for primary-study synthesis:

  • PICOC, research questions, keywords & search strings
  • Weighted quality assessment with cut-off score
  • Evidence-backed extraction & DOCX report
Reference: Kitchenham & Charters (2007), EBSE-2007-01

Systematic Mapping Studies

Petersen 2015

Structured classification and visualization of a research area:

  • Classification facets with reusable templates
  • Known-paper test set & Petersen checklist
  • Facet frequencies, cross-tab matrices & charts
Reference: Petersen, Vakkalanka & Kuzniarz (2015), IST

Rapid Reviews

Cartaxo 2020

Practice-oriented reviews with explicit documentation of methodological concessions:

  • Practical context & practitioner collaboration checklist
  • Screening rounds: titles → title & abstract → full text
  • Threats to validity drafted from concessions
Reference: Cartaxo, Pinto & Soares (2020), arXiv:2003.10006

{% trans "What you can do with Parsifal" %}

{% trans "Every feature works together on the same SQLite database, whether operated by researchers in the browser or by scripts and AI agents." %}

AI-Assisted Screening

Run Exclude with AI and Include with AI per round with per-criterion yes/no evaluation, customizable probability thresholds, AI relevance scores, and resumable run logs.

Multi-Reviewer Agreement

Record independent per-reviewer decisions, compute Cohen’s kappa for any pair of reviewers, inspect disagreements directly on the study window, and consolidate by rule.

Full-Text PDFs & BibTeX

Import BibTeX with search dates and duplicate detection, attach one PDF per study (local storage or S3-compatible bucket), star key studies, and open papers via DOI or institutional proxy.

Evidence-Backed Extraction

Record the exact supporting passage for each extracted value. Studies mark done only when every value has evidence, and all exports preserve that traceability.

PRISMA 2020 & Data Analysis

Inspect the PRISMA 2020 flow diagram (including round-by-round splits for rapid reviews), selection funnel, publications per year and source, quality scores, and mapping matrices.

Threats, Manuscripts & Exports

Document threats to validity with mitigations, keep versioned manuscripts with an in-page PDF viewer, and export protocols, studies, and extracted data to DOCX, XLSX, CSV, or JSON.

Audit History & Progress Bar

Track every change across protocol, search, selection, quality, and extraction — who made it, whether it was an amendment, and via Web, API, CLI, or MCP — with a live progress bar.

REST API, CLI & MCP

Automate any review step with personal API tokens at /api/v1/, the parsifal CLI, or the parsifal-mcp server for Claude Code, Codex, and other agents.

Self-Hosted, Backups & Dark Theme

Runs on a single SQLite file with Docker Compose, one-archive instance and per-review backups (database + PDFs), and light, dark, or system theme under Settings → Profile.

{% trans "Self-hosted on your own machine" %}

Run Parsifal locally on your laptop or on a small lab server without external database services. All protocols, studies, full-text PDFs, and manuscripts stay in one directory backed by SQLite.

  • Lightweight footprint: 1 vCPU, 512 MB–1 GB RAM, and disk space for your PDFs.
  • Zero extra services: Python 3.10+ or Docker Compose, SQLite database, and static files served directly.
  • Portable backups: export or restore the whole instance or a single review (DB + PDFs) in one archive.

bash — self-hosting quickstart 
# 1. Configure .env and bootstrap admin + API token
$ cp .env.example .env
$ docker compose run --rm parsifal init \
    --username alice --email you@example.org --token "laptop"

# 2. Start Parsifal (SQLite + files stored in ./data)
$ docker compose up -d

# 3. Back up the database and PDFs in a single archive
$ docker compose exec parsifal python manage.py backup
